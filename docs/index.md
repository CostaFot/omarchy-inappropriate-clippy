# Inappropriate Clippy — the manual

Clippy, on the [Omarchy](https://omarchy.org) bar, telling you what he thinks
of you. The [README](https://github.com/CostaFot/omarchy-inappropriate-clippy#readme)
is the short version — what he does, how to install him, how to slap him.
This is the rest.

- [Configuration](configuration.md) — every key, with its default
- [Letting your AI agent write his lines](ai.md) — `ai`, the screen look, talking back, `promptFile`
- [Giving him a voice](voice.md) — the espeak robot, `setup-voice`, clones, drop-ins, ducking
- [The graveyard](graveyard.md) — the public leaderboard and exactly what it sends
- [Scripting him](scripting.md) — every verb, Hyprland binds, hooks, and running him from a coding agent

Installed, these same pages sit in
`~/.config/omarchy/plugins/costafot.clippy/docs/` — that is the path
`omarchy-shell costafot.clippy help` ends with, so an agent on your machine
reads them without a network.
